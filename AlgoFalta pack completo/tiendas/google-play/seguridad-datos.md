# Formulario "Seguridad de los datos" (Play Console)

Debe coincidir con https://algofalta.com/privacidad. Ajustar si cambia la app.

**¿Recolecta o comparte datos?** Sí
**¿Datos cifrados en tránsito?** Sí
**¿Los usuarios pueden pedir que se borren?** Sí → https://algofalta.com/eliminar-cuenta

| Tipo de dato (Play) | Recolectado | Compartido* | Opcional | Finalidad |
|---|---|---|---|---|
| Información personal → Nombre | Sí | No | No | Funcionalidad, Gestión de cuenta |
| Información personal → Correo | Sí | No | No | Gestión de cuenta, Comunicaciones |
| Información personal → Teléfono | Sí | No | Sí (obligatorio solo para el bot) | Funcionalidad, Gestión de cuenta |
| Información financiera → Historial de compras | Sí | No | No | Funcionalidad (suscripciones) |
| Información financiera → Otra (montos de "Cuentas claras") | Sí | No | Sí | Funcionalidad |
| Mensajes → Otros mensajes (WhatsApp al bot) | Sí | No | Sí | Funcionalidad |
| Audio → Grabaciones de voz (notas de voz al bot) | Sí | No | Sí | Funcionalidad |
| Fotos (foto de perfil) | Sí | No | Sí | Personalización |
| Ubicación aproximada | Sí | No | Sí | Funcionalidad |
| Actividad en la app → Interacciones | Sí | No | No | Analítica |
| Info y rendimiento → Registros de fallos, Diagnósticos | Sí | No | No | Analítica |
| ID del dispositivo u otros | Sí | No | No | Funcionalidad (notificaciones) |

\* Según la definición de Google, enviar datos a **proveedores de servicios** que los procesan en tu nombre (Supabase, Meta, proveedor de IA, Alegra) **no** cuenta como "compartir".

No marcar: ubicación precisa, contactos, salud, calendario, archivos, navegación web.
