# AlgoFalta

Lista de mercado compartida para Colombia (Android e iOS). Los grupos viven en la app; con el plan Plus se conectan a WhatsApp, donde un bot de IA arma la lista desde la conversación. Incluye "Cuentas claras": quién pagó qué y cómo saldar cuentas en partes iguales.

## Estructura

- `docs/` — Plan de negocio y manual de identidad de marca.
- `landing/` — Landing page (HTML estático). Logos de terceros en `landing/logos/`, fotos y créditos en `landing/img/`.
- `app/` — App móvil (React Native + Expo). Pendiente.
- `supabase/` — Base de datos, auth y tiempo real. Pendiente.
- `bot/` — Webhook de WhatsApp Cloud API y agente de IA. Pendiente.
